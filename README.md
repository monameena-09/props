# React Job Cards

A simple job listing UI built with React to practice **Props, reusable components, and dynamic data rendering**.

## 🚀 About the Project

This is my first React project focused on understanding how **Props** work.

The project displays job cards for different companies with information such as:

- Company name
- Job role
- Work type
- Experience level
- Salary
- Location
- Posted time
- Company logo

Each job card is created using a reusable React component, with different data passed through Props.

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## 📚 What I Learned

Through this project, I practiced:

- Creating React components
- Passing data using Props
- Reusing components
- Rendering multiple cards using `.map()`
- Working with images and assets
- Structuring a React project
